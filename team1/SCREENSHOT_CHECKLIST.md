# MediConnect Client Demo Screenshot Checklist

## Instructions
Capture screenshots at 1920x1080 (Desktop) and 390x844 (Mobile - iPhone 13/14 Pro). Use Incognito mode to avoid cached data artifacts.

## Required Screenshots

### 1. Authentication
- [ ] **Login Page**: Clean UI, email/password fields, "Forgot Password" link.
- [ ] **Registration Page (Step 1)**: Personal info form, role selector (Patient/Doctor).
- [ ] **Registration Page (Step 3)**: Doctor professional info with Availability Grid visible.

### 2. Dashboards
- [ ] **Patient Dashboard**: Stats cards (Upcoming, Completed), quick action buttons.
- [ ] **Doctor Dashboard**: Pending approvals, today's schedule, metrics.

### 3. Core Features
- [ ] **Appointment Booking**: Doctor profile modal, date picker, time slot selection.
- [ ] **My Appointments (List)**: Filter tabs (All, Today, This Week), Search bar, "Navigate to Clinic" button visible for offline appointments.
- [ ] **Google Maps Navigation**: Screenshot of Google Maps opening with clinic coordinates pre-filled.

### 4. Reports & Notifications
- [ ] **Reports Page**: Table view with View, Download, and Delete buttons. Delete confirmation modal visible.
- [ ] **Notifications Page**: Real-time list with "Mark All as Read" button, unread indicators.

### 5. AI Chatbot
- [ ] **Chatbot Interface**: Open chat window.
- [ ] **Natural Language Intent**: Screenshot of user typing "I need a cardiologist tomorrow" and bot responding with routing action/button.

## Delivery Format
- Compile all screenshots into a single PDF or a dedicated `/docs/screenshots` folder.
- Name files descriptively: `01_login_desktop.png`, `02_booking_mobile.png`, etc.
